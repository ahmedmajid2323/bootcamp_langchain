# 🚀 Bootcamp: Agentic & Generative AI with LangChain

## 📚 Introduction

In this project, we dive into the exciting world of **LangChain**, **Agentic AI**, and **Generative AI**:  

- **LangChain** is a powerful framework designed to help developers build applications with **Large Language Models (LLMs)**, enabling easy chaining of prompts, tools, and APIs.  
- **Agentic AI** refers to building intelligent agents that not only respond to prompts but also make decisions, use tools, and interact autonomously to achieve goals.  
- **Generative AI** allows systems to produce new content, such as text, summaries, and insights, through advanced language models.

## 🚀 Getting Started

### 1️⃣ Clone the repository:
```bash
git clone https://github.com/your-username/your-repo-name.git
```

### 2️⃣ Install dependencies:
```bash
npm install
```

### 3️⃣ Get your API key from Groq:
 - Visit [Groq Cloud](https://groq.com/groqcloud/)
 - Create an account and generate your API key.

### 4️⃣ Set up the .env file :
 - In the root directory (next to package.json and package-lock.json), create a file called .env.
 - Add the following line with your API key:
```bash
export GROQ_API_KEY="your-api-key-here"
```

✅ Everything is now set up! You’re ready to start learning and building.
run the code with : 
```bash
npx nodemon file_path
```

## Detailed Module Descriptions
### 1. Chat Models, Prompt Templates, Chat History & Parsers :
 - Learn how to communicate with LLMs effectively.
 - Create prompt templates that structure requests to the model.
 - Manage chat history for context-aware conversations.
 - Use parsers to convert model responses into structured data or actionable output.

### 2. Chains (Extended, Parallel, and Branches) :
 - **Extended chains:** Combine multiple steps into complex pipelines.
 - **Parallel chains:** Run several tasks at once and merge results.
 - **Branching chains:** Make dynamic decisions within chains based on conditions and outputs.

### 3. Summarization :
We will explore different approaches to text summarization using LangChain:
 - **Map-Reduce:** Break large texts into smaller chunks, summarize each, and combine the results.
 - **Refine:** Iteratively improve summaries by processing chunks and refining previous outputs.
 - **Clustering Method:** Use clustering techniques to group similar content and generate summaries that represent each cluster for more insightful and structured outputs.

### 4. Retrieval Augmented Generation (RAG) :
 - Use external knowledge bases and search tools.
 - Retrieve relevant documents or data in real-time to enrich LLM responses.
 - Build intelligent QA systems that combine generative models with real-world information.

### 5. **Agents and Tools**
In this module, we will go in-depth into building and using tools and agents:

#### ✅ Custom Tools:
Learn how to create your own tools for agents, including:
- API calls
- RAG-based tools
- Chains as tools
- Custom functions

#### ✅ Agent Types:
Explore different types of agents and their functionalities:
- **ReAct Agents** — agents that reason and act step-by-step.
- **ReAct-Chat Agents** — agents capable of maintaining dialogue and deciding actions mid-conversation.
- **Structured-Chat Agents** — agents with structured input/output formats for more controlled and predictable behaviors.

#### ✅ Agent Functionalities:
- Learn how agents use tools autonomously.
- See how they decide which tool to call next and how to handle multi-step problem-solving.
